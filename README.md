HR Employee Data Analysis Using Databricks SQL

Project Overview

Analyzed HR employee data to understand salary distribution, department-wise employee details, work experience, and attendance.

Tools & Technologies

- Databricks SQL
- SQL
- Delta Lake
- HR Dataset

Key Tasks

- Calculated department-wise employee counts and average salaries.
- Identified highest-paid employees using window functions.
- Calculated employee attendance percentages.
- Used JOINs, GROUP BY, subqueries, and RANK().
- Created a permanent Delta table named "employee_analysis".

Outcome

Gained practical experience in SQL-based data analysis and Delta table management using Databricks.
